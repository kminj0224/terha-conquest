# Terha Conquest v1.10.68

- 국가 선택과 정복 기록을 전체화면으로 표시합니다. 국가 선택은 테르하 전체지도 배경과 기존 국가·난이도·시작·저장·이어하기 버튼을 사용합니다.
- 전장·기록 버튼을 확대하고 지도·책 일러스트를 넣었습니다. 도움말은 ?, 설정은 톱니바퀴만 표시하며 접근성 이름은 유지합니다.
- 시작·메인 메뉴·국가 선택·기록·도움말·설정에서 메뉴 음악을 이어서 재생합니다. 작전처럼 메뉴 음악이 없는 화면에서 돌아오면 처음부터 재생합니다. 음량 0과 앱 백그라운드 전환은 재생 위치를 보존합니다.
- 새 정복 기록에 난이도를 함께 저장합니다. 예전 기록에 난이도가 없으면 임의로 추정하지 않고 미기록으로 표시합니다.
- 지도 로딩을 기다리지 않고 시작화면을 먼저 표시합니다. 최초 HTML에서도 게임 HUD를 감춰 실행 직후 다른 버튼이 보이는 현상을 막습니다.
- 기존 저장 데이터와 서명 인증서를 유지합니다. versionCode: 112. 빌드: python3 build.py.
- 자동 기능 검사와 원래 Android 셸 검사를 실행했습니다. 실제 휴대폰의 최종 화면·스피커 음향은 별도 확인이 필요합니다.

## 이전 v1.10.67 기준 안내

# Terha Conquest v1.10.67

v1.10.65 APK의 게임 파일과 Android 셸을 기반으로 수정했습니다. 별도 초기 소스의 RSA 서명 키·인증서는 업데이트 서명에 사용합니다. v1.10.66의 한사 섬 지형은 v65 기반에서 재구현했습니다.

## 변경 사항
- 앱 실행 시 첨부 항구 배경을 전체화면 cover로 표시하고 게임 제목과 중앙 점멸 START 버튼을 표시합니다.
- START 다음 화면에는 중앙 전장·기록, 오른쪽 하단 도움말·설정을 표시합니다. 전장은 국가 선택으로 연결하며 국가 선택과 작전 지휘소에서 게임 제목과 긴 도움말을 제거했습니다.
- 정복 성공 기록은 국가·성공 턴·성공 날짜를 저장하며, 턴이 짧은 순으로 정렬합니다. 작전 식별자를 저장하여 같은 작전 결과의 중복 등록을 막습니다.
- 음악·효과음 음량을 별도로 조절하고 한국어/영어 설정을 저장합니다. 첨부 MP3는 시작·메인 메뉴·기록 화면에서 반복 재생하며 작전 진입 시 멈춥니다. 영문 유닛 명칭·특성·설명과 도시 이름 표기를 추가했습니다.
- Android 뒤로가기를 화면 이동과 연결했습니다. 작전에서 나갈 때 예/아니오 확인 후 자동 저장하고 메인 메뉴로 돌아갑니다. AI 진행 중 나가기를 선택하면 빠르게 남은 턴을 정리하여 저장하며, 정리 중 새 작전 진입은 잠깁니다.
- 수동 슬롯에 삭제 버튼과 삭제/덮어쓰기 확인창을 추가했습니다. 자동 저장과 수동 슬롯은 별개입니다.
- 전체화면 작전 로딩 이미지에 진행 바를 추가했습니다. 준비·지도 생성·이미지 디코딩·실제 지도/유닛 프레임 완료 단계에 따라 갱신합니다.
- 단테 수도에 적이 3타일 이내 접근하면 좌우 1타일 위치에 첨부 귀신 두 개를 약 3타일 높이로 표시합니다. 서로 마주보도록 반전하며 서서히 나타나 반투명 범위에서 점멸합니다. 수도 함락 후에도 원래 단테 진영의 적 관계를 기준으로 작동하고 조건 해제 시 사라집니다.
- 보병 사망 흔적을 첨부 이미지로 교체했습니다. 기존 사망 표시 지속·감쇠는 유지합니다.
- 한사 12타일을 바다로 바꾸어 육지 10타일의 섬을 구성하고 북쪽 만·해협의 지도 그림과 지형 레이어를 수정했습니다. 수도, 동쪽 지대공 포대, 네 방향 다리는 유지합니다. 기존 저장의 새 수역 위 지상 유닛·시설은 가까운 적절한 육지로 옮깁니다.
- 기존 도시명, 마리아항 수역, 유닛 초점, 전투·이동·버튼 효과음은 유지합니다.

## 빌드
Python 3 및 Java 17이 필요합니다. `python3 build.py`로 사전 제작된 game/assets를 패키징하고 tools의 원래 키로 서명합니다. Android 패키지와 저장 경로를 유지하며 versionCode는 111입니다. 빌드에 필요한 ECJ·apksig JAR도 포함합니다.

## 검증
`node qa/native-test.cjs`는 @napi-rs/canvas를 사용하는 실제 지도 렌더러와 DOM·오디오 대체 환경에서 메뉴 이동, 음량, 영문 설정, 로딩 완료, 저장 확인창, 뒤로가기, 이어하기, 한사 섬/수역 규칙, 단테 귀신의 범위·함락·등장/소멸, 보병 사망 흔적, 기록 중복/정렬, 손상된 저장 실패를 검사합니다. 런타임 픽셀 읽기 없이 작동함을 확인합니다.
`python3 qa/verify-native.py`로 Android 셸의 DEX 표·체크섬 및 뒤로가기/자동재생 호출을 확인합니다. APK 빌드 후 v65와 서명 인증서를 비교합니다. Android 실기기 실행·음향 청음은 수행하지 않았습니다.

## 파일
- game/assets: 전체 게임과 첨부 배경·음악·그림, 영어 번역 및 화면 코드
- android/native-shell.zip: v65 Android 셸의 뒤로가기/미디어 설정을 수정한 파일
- tools: 빌드·서명·업데이트 확인 및 PCM 은행의 개별 WAV 내보내기
- qa: Canvas 검증과 지형/네이티브 변경 스크립트. 지형은 사전 제작되어 일반 빌드에 재제작이 필요하지 않습니다.
