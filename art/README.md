# Aligned high-resolution map — v1.11.6

The original v1.11.4 gameplay data is authoritative. Mountains retain their original sprites and exact mountain-tile anchors. Each non-city forest tile has a complete climate-specific tree group, rooted on that tile and avoiding the maximum upgraded city envelope with 8 world units of margin. Channels use the original river sampler, normals and widths. Gameplay data, faction/type IDs and save compatibility are unchanged.

Imagegen supplies materials and isolated tree sprites only. It does not place geographic features. Snow covers Sielun and the disconnected Baekyang northern islands; Stetopia is temperate; Ayria has desert and cacti; Ranna/Nakwol use tropical palms; Dante is barren with black leafless trees. Biomes use original geography, never occupation. Source PNGs and prompts belong in terrain-materials/.

The coast comes from the original land hex union, smoothed into a signed distance field. All land/water tile centers retain their classification. Fine beach, shallows and irregular foam follow the coast. 48 overlapping JPEG94 regions at 1254 square form an effective 8688x6516 atlas. The overview uses the same final artwork. Runtime decodes visible regions only, limits its LRU to 80 MiB, caches stationary views and performs no pixel scans.

Rebuild with `node tools/export-aligned-geometry.cjs` then `node tools/bake-aligned-map.cjs`. The exported geometry and composition manifest record every terrain anchor and river sample. Run `node qa/aligned-map-regression.cjs`, `node qa/hd-map-regression.cjs`, `node qa/natural-map-view.cjs` and `npm test`. Exact terrain placement, full river geometry, all coastline tile centers, complete tree bounds against city envelopes, every rendered region hash and unobstructed river pixel samples are checked. Runtime tests use real Canvas with simulated DOM/audio; they are not physical Android tests. CI retains the original Android shell and signing key, verifies the APK and commits generated images before release.
