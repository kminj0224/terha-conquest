# v1.11.70 mechanical hit correction

The v68 shared armor-hit renderer drew the dirt-explosion strip unconditionally for both flesh and mechanical targets. Mechanical routing still correctly selected `armorSmoke`, but the shared renderer added an unwanted explosion beneath its spark. v69 inherited that mistake.

Only the flesh-target branch now calls `drawDirtImpact`. Armor and anti-tank infantry hitting mechanical targets display the existing large initial spark and simultaneous looping black smoke. Infantry-target dirt/blood effects, artillery/air/naval fire explosions, unit-foot explosion anchoring, smoke timing and depth ordering are unchanged.

The real Canvas regression covers 105 attacker/mechanical-target combinations and throws if any uses the dirt renderer or any non-spark atlas row. It also requires both spark and smoke stages. Existing ground/sequence/routing/build/signature checks remain. The full native suite retains its existing mission02 prepared-playthrough failure; this correction changes rendering only.
