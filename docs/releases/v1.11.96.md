# 테르하 : 낙원의 기억 v1.11.96

- 메인캠페인의 ‘2차 선석전쟁’을 누르면 스테이지 선택 페이지로 이동합니다.
- 승인된 2안의 세로 포스터 구성으로 01~10 스테이지를 표시합니다. 넓은 화면은 5열 × 2행, 좁은 화면은 2열로 배치합니다.
- 팝업 형태의 테두리·바깥 여백·닫기 버튼·시안 전환 버튼을 제거했습니다. 상단 ‘캠페인 목록’ 버튼과 뒤로가기로 목록에 복귀합니다.
- 미클리어 스테이지는 잠금으로 표시합니다. 이번 릴리스는 선택 페이지를 추가하며 새로운 전투 임무를 해금하지 않습니다.
- 기존 정복·서브캠페인 저장과 전투 규칙, 앱 패키지 및 업데이트 서명을 유지합니다.
- Android 버전 1.11.96, versionCode 241.

검증: 전체 npm 회귀 검사, 메인캠페인 서막·페이지 및 공유 캠페인 Chromium 검사, 네이티브 셸 검사, APK 패키지·버전·기존 인증서·페이지 리소스 일치 검사.
