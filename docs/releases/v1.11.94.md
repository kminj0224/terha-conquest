# 테르하 : 낙원의 기억 v1.11.94

- 사용자가 선택한 1안(검붉은 초고층 제국도시)을 단테 제국 도시의 정식 기본 이미지로 적용했습니다. 비교 시안과 동일한 이미지와 표시 크기를 사용합니다.
