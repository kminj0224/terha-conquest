# 테르하 : 낙원의 기억 v1.11.91

- 가르다라 특수유닛 '아마라한을 지키는 힘무리'가 일반 보병과 비슷한 크기로 표시되도록 조정했습니다(64×80 → 40×50 게임 화면 좌표).
- 압축된 이미지의 뭉개짐이 덜 눈에 띄도록 특수유닛 그림에만 명암 보정과 고품질 축소 렌더링을 적용했습니다.
- 원본 사격 이미지의 네 총구 위치를 새 크기에 정확히 투영해 좌우 연발사격 섬광·발사 출발점이 일치하도록 했습니다.
- 대기/사격 아트워크, 다른 가르다라 보병 이미지, 능력치·생산 조건·기존 저장 데이터는 유지됩니다.
- 전용 영상 회귀 테스트에 특수유닛 크기 및 총구 좌표 확인을 추가했습니다.
- 기존 Android 패키지·업데이트 서명과 앱 아이콘을 유지합니다.
