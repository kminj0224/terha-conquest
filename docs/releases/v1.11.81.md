# v1.11.81 — 메인 캠페인 서막 이미지와 음악

- 페이지 2~12: 한례사 선석, 13~22: 전쟁, 23~30: 카오 안잉, 31~33: 백양국 도성.
- 페이지 37~38: 마리아, 39~40: 유적 탐사대, 41~45: 후피왕 피라미드.
- 가로 화면 배경을 cover로 채우며 화면 비율에 따라 중앙 기준 가장자리를 자른다. 버튼과 본문은 안전 영역을 유지한다.
- 타이핑 간격을 14ms에서 42ms로 변경한다. 기존 타이핑 완료 후 다음 버튼과 중앙 문구 자동 전환은 유지한다.
- 2~33페이지에서 Ruins of the Deepwood 반복, 37~45페이지에서 무덤의 리듬 반복. 1/34/35/36페이지 및 캠페인 선택 화면은 무음.
- 메인캠페인을 누르면 메뉴 음악을 즉시 종료한다. 같은 음악 구간의 페이지 전환은 재생 위치를 유지한다. 건너뛰기/이탈은 음악 종료, 음량/음소거/앱 숨김은 공통 설정에 따른다.
- 이미지 7장과 MP3 2곡은 제공 원본을 그대로 APK에 포함한다.
- Android versionCode 226. 기존 패키지와 업데이트 서명 인증서를 유지한다.

검증: 45페이지 데이터/타이핑/전환/음악 범위/동일 구간 연속 재생/음소거/숨김/Skip/이탈의 독립 회귀검사, Android 셸 검사, APK ZIP 자산 동일성 및 기존 인증서 서명 검증 통과. Chromium의 5개 화면 크기 및 기존 캠페인 공유 엔진 검사는 GitHub Actions에서도 실행한다.
