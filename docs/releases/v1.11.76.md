# v1.11.76 — 한사 교각 터치 및 피·스파크 피격 효과

## 변경 사항

- 한사 교각의 8개 제어 건물은 확대 배율과 관계없이 최소 48 CSS 픽셀 크기의 터치 영역을 사용합니다. 그림 크기는 유지하며, 겹치는 영역에서는 실제 건물과 더 가까운 제어 지점을 우선합니다.
- 제어 건물과 같은 육각칸에 유닛이 있다는 이유로 건물 클릭이 무시되던 조건을 제거했습니다. 교각 위 아군·동맹군의 차단 방지, 해군이 있을 때 재연결 방지 및 확인창은 유지합니다.
- 피와 스파크에 공격이 들어온 좌우 방향을 기록해 수평 반전합니다. 일반 효과, 기갑 피격 스파크, 사프로스와 백야의 밤 전용 효과를 포함합니다.
- 피와 스파크는 국가·유닛별 실제 그림의 중앙에 배치합니다. 이동 중인 대상은 현재 그림의 위치를 따르고, 격파된 대상은 피격 위치를 유지합니다. 지도의 좌우 경계에서도 실제 최단 공격 방향을 사용합니다.
- 폭발, 흙먼지, 연기의 위치·크기·타이밍과 피해 수치는 유지합니다. 기존 피·스파크 이미지와 재생 시간도 유지합니다.
- 중앙 좌표는 256개 국가/유닛 조합의 실제 이미지에서 오프라인으로 측정한 압축 데이터입니다. 게임 중 픽셀 읽기나 피격마다 캔버스 생성이 없습니다.

## 검증

- `node qa/release-v11176-native.cjs`: 실제 pointerdown/up 입력, 네 교각 양끝과 네 확대 배율의 64회 터치, 기존 차단/연결/저장/AI 동작, 피·스파크 56개 피격 조합, 이동·격파·광역·세계 경계 및 폭발/연기 5개 유형 불변 검사.
- `node qa/combat-animation-native.cjs`: 기존 전투 래스터 효과와 애니메이션 단계 검사.
- `node qa/combat-impact-routing-native.cjs`: 도시/주둔군과 광역 피격 분리 검사.
- `node qa/conquest-ai-simulation.cjs`: v1.11.75 정복 AI 규칙 유지 검사.
- 기존 Android 셸·서명 검증과 `python3 build.py`.

versionCode 221. 기존 앱 식별자, 업데이트 인증서 및 저장 데이터 형식을 유지합니다. 네이티브 Canvas 검사는 DOM/오디오를 모사하며 실기기 Android 검사를 뜻하지 않습니다.
