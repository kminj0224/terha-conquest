# 테르하 : 낙원의 기억 v1.11.90

- 가르다라 특수유닛 ‘아마라한을 지키는 힘무리’의 기본 대기 그림을 제공된 검은 장갑 소총수 네 명의 이미지로 교체했습니다.
- 사격 시에는 두 번째 제공 이미지의 조준 자세로 전환합니다.
- 네 자루 소총의 총구 끝 위치를 사격 원본(1122×1402)의 픽셀 기준으로 별도 지정하고, 좌·우 방향의 연발 총구섬광 및 투사체 시작 위치가 일치하도록 설정했습니다.
- 기존 8연발 사격, 특수유닛 능력치와 생산 조건은 유지했습니다.
- 일반 가르다라 소총수와 다른 국가 유닛 그림은 변경하지 않았습니다.
- 두 이미지의 로딩, 정확한 사격 총구 좌표, 연발 32발, 좌·우 방향 전환을 검증하는 자동화 회귀 테스트를 추가했습니다.
- 기존 게임 세이브와 Android 서명, 앱 패키지명 및 런처 아이콘은 유지했습니다.
