# v1.11.80 — 서막 자동 전환과 타이핑 후 다음 버튼

- 중앙 문구 페이지의 이전/다음 버튼과 페이지 번호를 제거한다. 화면 터치, 화살표 키, Enter/Space 및 휴대폰 뒤로가기로 페이지를 넘기지 않는다. 상단 Skip은 유지한다.
- 검정 화면은 1초 대기 → 0.85초 페이드인 → 완전히 표시된 상태로 3초 유지 → 0.85초 페이드아웃 → 다음 페이지 자동 전환 순서다.
- 이미지가 있는 중앙 문구는 기존 2초 대기를 유지하며 같은 페이드인/3초 유지/페이드아웃/자동 전환을 사용한다.
- 하단 배너 문구는 타이핑 중에 다음 버튼을 숨기고 조기 넘김을 막는다. 타이핑이 완전히 끝나면 오른쪽 아래에 > 버튼 하나가 나타난다. 배경 터치나 이전 버튼으로 이동하지 않는다.
- Skip·다시보기·화면 이탈 시 기존 애니메이션을 취소한다. 앱이 숨겨진 동안에는 서막 진행 시간을 멈춘다.
- 사용자 원문 45장, 첨부 이미지, 배너 글자 크기/그라데이션, 캠페인·정복 저장과 전투 규칙을 유지한다.
- Android versionCode 225. 기존 패키지 및 업데이트 인증서를 유지한다.

## 검증

- 전용 Node VM에서 정확한 타이밍 경계, 중앙 문구 수동 넘김 차단, 타이핑 완료 후 버튼 노출, Skip 취소, 백그라운드 시간 정지 및 45장 순회를 검증했다.
- Chromium에서 네 가지 화면 크기의 45장 전체를 검증했으며 기존 캠페인 선택창/공유 전투 UI 검사도 통과했다.
- 전체 npm test에는 기존 인계 문서에 기록된 임무02 자동 플레이의 27턴 패배가 있다. 이번 변경은 임무 규칙이나 밸런스를 수정하지 않는다.
