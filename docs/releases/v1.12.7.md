# 테르하 : 낙원의 기억 v1.12.7 — 항공 생산과 요격

- 항공기는 생산 명령 후 다음 자기 턴에 도시 재고로 완성됩니다. 도시당 턴당 생산 1회이며 지상·해군 생산과 제한을 공유합니다. 진행 작업에 표시하고 저장·불러오기에도 유지합니다.
- 공수강하 자원·사거리·전투기 소모를 공통 아이콘 비용 줄로 표시합니다. 유효한 출격당 출격 가능한 전투기 1대를 영구 소모합니다. 잘못된 목표에는 재고·자원을 차감하지 않습니다.
- 요격 전투기가 공항에서 교전 지점으로 출격합니다. 양측 교전 효과 후 패배한 쪽만 연기를 내며 추락합니다. 생존기는 귀환하며 핵 폭격·공수강하에도 같은 요격 연출을 적용합니다.
- 공항 창의 긴 안내 문장을 제거하고 명령·재고 위주로 정리했습니다. 도시 연구·시설·전략무기의 공통 자원 줄을 기존 자원 아이콘으로 통일했습니다. 도움말의 항공 규칙과 비용은 표로 정리했습니다.

검증: 전체 네이티브 회귀 검사, 항공 생산·공수강하·양측 요격·실제 저장 검사, 원본 및 출시 WebP 묶음의 Chromium 화면과 작은 화면 조작 검사, 무손실 이미지 비교, APK 버전·기존 서명 검사. 실제 Android 기기 검사는 별도입니다.
