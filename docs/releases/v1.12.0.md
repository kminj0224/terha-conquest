# 테르하 : 낙원의 기억 v1.12.0

- 미사용 지도 레이어·구버전 이미지·스크립트 323개를 정리했습니다.
- 제작·검증용 원본을 APK에서 제외했습니다.
- 게임에 포함되는 PNG 이미지를 GitHub Actions에서 무손실 WebP로 변환합니다.
- 변환 전후 모든 RGBA 픽셀과 해상도가 동일한지 검사합니다. Android 런처 drawable은 PNG 규격을 유지합니다.
- 실제 WebP 번들로 정복 모드, 캠페인 전투, 메인 프롤로그와 인물 대화를 Chromium에서 검증합니다.
- 앱 패키지명과 기존 업데이트 서명 인증서를 유지합니다. versionCode는 245입니다.

원본 이미지는 제작용 소스에 보존되며 APK에는 변환된 WebP와 갱신된 참조만 들어갑니다.
릴리스에 첨부된 `webp-conversion-report.json`에는 각 이미지의 크기·해시·픽셀 검증 결과가 기록됩니다.
