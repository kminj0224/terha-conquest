# 테르하 : 낙원의 기억 v1.11.88

- 수송기 공수강하가 별도 무단계 공수부대(기본 공격 52, 최대 체력 211)를 투하합니다.
- 국가별 기존 소총수 일러스트와 소총 위치를 사용하되, 중기관총병의 연속 총구섬광과 연발사격 음향을 적용합니다.
- 방어시설 피해 200배, 3레벨 이하 도시 피해 500배를 적용합니다.
- 강하 2턴 뒤 이동·공격·반격 및 기타 행동이 중지됩니다. 근거리의 다른 공수부대는 지원으로 간주하지 않습니다.
- 3타일 내 같은 국가의 비공수 아군이 접근하면 4단계 소총수로 전환되며 첫 행동 시에만 해당 소총수 식량 생산비가 지불됩니다.
- 박격포 이동력을 1로 변경하고 이동·공격의 석유 소비를 0으로 설정합니다.
- 기존 게임 저장, 병종 ID, Android 업데이트 서명 및 설치 패키지는 유지합니다.
