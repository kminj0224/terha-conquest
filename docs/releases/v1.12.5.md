# 테르하 : 낙원의 기억 v1.12.5 — 연구 표시 통일

- 전투기 성능 개선·스텔스 연구를 기존 연구와 같은 행으로 표시합니다. 첫 줄은 연구명과 단계, 아래 작은 줄은 골드·석유·연구 기간이며 정보 버튼에는 효과만 표시합니다.
- 진행 배너는 기존 공통 진행 카드의 연구명·단계, 남은 턴, 효과 설명, 진행 막대를 그대로 사용합니다. 전투기 성능의 이전→다음 단계와 스텔스 연구의 실제 격추 확률 변화(예: 60% → 55%)를 표시합니다.
- 배너는 연구하는 도시에만 표시하고, 작업 중인데도 “진행 중인 작업이 없습니다”가 함께 나오던 표시를 수정했습니다. 스텔스 10단계는 완료로 표시하며 11단계를 제안하지 않습니다.
- 한국어·영어에 동일하게 적용합니다. 항공 전투·생산비·연구비·효과·저장 형식과 기존 Android 앱 ID 및 서명은 유지합니다.

검증: 기존 도시·연구 UI 검사, 공항 재고 엔진 검사, 원본 및 출시용 WebP 묶음의 실제 Chromium 화면 검사, APK 버전·기존 업데이트 서명 검사. 실제 Android 기기 검사는 별도입니다.
