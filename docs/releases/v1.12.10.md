# 테르하 : 낙원의 기억 v1.12.10

- 자주포 기본 체력 130, 장갑 25.
- 다연장로켓포 기본 체력 120, 장갑 20.
- 지대공미사일의 기본 항공기 격추 확률 50%. 스텔스 연구는 단계당 5%p 감소하여 10단계에서 0%가 됩니다. 연구 안내·진행 표시·도움말도 같은 기준으로 변경했습니다.
- 도시 항공 탭에 기종별 가져오기 추가. 항공기가 남아 있는 아군 공항을 선택하고 원하는 수량을 가져올 수 있습니다. 출발 도시별 재고와 출격 가능한 수량이 표시됩니다.
- 기존 이송과 동일하게 가져온 항공기는 다음 자기 턴부터 출격할 수 있습니다.
- 이전 저장의 자주포·다연장로켓포는 피해 비율을 유지하여 새 체력을 적용합니다. 새 저장을 다시 불러올 때 체력이 변하지 않습니다.
- Android 패키지와 기존 서명을 유지하며 versionCode 255로 업데이트합니다.
