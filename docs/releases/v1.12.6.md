# 테르하 : 낙원의 기억 v1.12.6 — 항공기 재고 표시 통일

- 항공기 재고를 핵탄두 재고와 동일한 공통 일반 재고 글꼴·색상·굵기로 표시합니다. 별도 금색 제목 강조를 제거했습니다.
- 스텔스 연구 정보에는 효과만 표시합니다. 과학연구소가 없으면 기존 연구처럼 실행 불가 사유로 안내합니다.
- 연구 조건과 항공 전투·생산·저장 규칙은 유지합니다.

검증: 공항 엔진과 실제 브라우저의 재고 스타일 비교, 연구 정보 및 연구소 조건 확인, 원본·출시용 WebP 묶음의 한·영 화면, APK 버전·기존 업데이트 서명 검사. 실제 Android 기기 검사는 별도입니다.
