# 테르하 : 낙원의 기억 v1.12.3

- 공항과 전투기 해금 레벨을 갖춘 본토 도시에서 초계 전투기를 생산할 수 있습니다. 폭격기 등 다른 고정익 항공기는 기존 공항 임무로 운용합니다.
- 전투기 정보창의 **초계 개시**는 석유 8을 소비합니다. 반경 4타일에서 적 공항의 일반 공습을 요격하고 자국 공습을 호위합니다. 남은 이동·공격·일반 반격을 포기하며 다음 자국 턴 시작에 초계가 종료됩니다.
- 초계기는 자국 턴 주기마다 요격·호위 합계 2회까지 참가합니다. 임무마다 양측 최대 2개 전투기 부대가 교전하며 체력 손실을 받습니다. 다른 국가의 턴은 초계 횟수를 회복시키지 않습니다.
- 기체 체력·편제 단계·목표와의 거리에 따라 제공력이 달라집니다. 공역 버튼에서 아군·적·중첩 범위를 확인할 수 있습니다.
- 일반 공습 목표를 누르면 요격·호위 편대 수, 예상 돌파율, 지대공 보호 및 목표 대공장비 유무를 확인하고 출격 여부를 선택합니다. 취소하면 자원과 초계 횟수를 소비하지 않습니다. 실제 부대·도시·주변 폭격 피해에 동일한 돌파율을 적용하며 기존 방공 보호는 유지합니다.
- AI가 초계 전투기를 생산·배치하며 요격이 강한 공습을 피합니다.
- 초계 상태와 남은 횟수를 저장합니다. 기존 저장 및 Android 앱 ID·업데이트 서명을 유지합니다.
- 한국어·영어 도움말에 생산 방법, 초계 비용과 지속 기간, 요격·호위, 공역 색상, 공습 예상창 및 적용 범위를 추가했습니다.

이번 제공권 규칙은 공항의 전투기 공습·폭격기 공습·일반 전략폭격에 적용합니다. 공수강하·핵 임무·지도 위 항공기의 직접 공격은 기존 규칙을 따릅니다.

검증: 실제 게임 엔진 제공권 회귀 검사, 기존 Native Canvas 회귀 검사, 원본 및 무손실 WebP 번들의 Chromium 모바일 UI 검사, Android 셸·앱 이름·기존 서명 인증서 검사. 실제 Android 기기에서의 터치·음향·성능 검사는 포함하지 않습니다.
