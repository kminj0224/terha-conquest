# v1.11.79 — 메인 캠페인 서막

- 전장 → 캠페인 → 메인캠페인에서 선석전쟁 서막 45장을 재생한다.
- 이미지 페이지에는 사용자가 첨부한 이미지를 사용한다. 검정 화면 지정 페이지에는 그림이 없다.
- 하단 배너의 흰색 한글 타자체는 14ms/문자 간격으로 나타난다. 중앙 80%는 불투명 검정이며 좌우 10%가 투명으로 이어진다. 같은 화면 크기에서는 모든 하단 문구의 글자 크기가 같다.
- 중앙 문구는 각 페이지 진입 후 2초 대기하고 0.85초 동안 페이드인한다. 이전 페이지로 돌아와도 다시 재생된다.
- 화면 터치와 하단 < >로 페이지를 이동한다. 상단 Skip 또는 마지막 장 다음에서 메인 캠페인 선택 화면으로 이동한다.
- 선택 화면에 2차 선석전쟁과 서막 다시 보기를 제공한다. 전투 임무는 아직 추가하지 않는다. 기존 서브 캠페인과 정복 저장은 그대로 유지한다.
- 원본 Nanum Gothic Coding의 서막용 글리프를 포함한 독립 이름의 OFL 글꼴을 동봉한다. 글꼴·이미지·텍스트는 오프라인에서 동작한다.
- Android versionCode 224. 기존 패키지 및 업데이트 서명을 유지한다.

## 검증 상태

- 전용 Node VM 검사에서 45장 순회, 타이핑 진행·취소, 이전/다음/터치/Skip/Back/다시보기, 선택화면 이동을 검증했다.
- 원본 업데이트 인증서 및 Android 셸 검증을 통과했다.
- 전체 Chromium 검증은 배포 워크플로에 포함한다. 현재 로컬 실행 환경에서는 Chromium 프로세스가 시작되지 않아 브라우저 실측은 실행하지 못했다.
- 전체 npm test는 기존 AGENTS.md와 캠페인 인계 문서에 기재된 임무02 prepared 탈환 참조 봇의 27턴 패배에서 실패했다. 그 전의 공유 엔진·해군 제외·도시 제한·지형/평가·임무02 기본 검사는 통과했다. 기존 임무 규칙이나 밸런스는 변경하지 않았다.
