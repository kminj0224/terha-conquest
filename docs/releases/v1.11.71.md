# v1.11.71 flowing smoke columns and two depth layers

The supplied drawing calls for a continuous sinuous column that originates near the hull/hit point, carries curls upward, widens and disperses above. It does not call for a round smoke clump that merely changes opacity. The pointed lower tail was subsequently replaced with a short rounded, feathered emission patch.

Five realistic illustrated source columns are sampled with an upward-moving texture coordinate. Source/destination row bounds preserve the column envelope while its texture flows upward, rather than translating a rigid sprite. Upper curls bend and spread. Emission stops at about 1.2 seconds, clears progressively from below, and the remaining elevated plume disperses by about 3 seconds. There are two independently phased/winding animation sets, each with 40 shared cached frames.

Unit hits and mechanical wrecks have a higher rear stream (depth rank 2.8) and a smaller/lower front stream (depth rank 3.5), with the unit/wreck body between them at rank 3. Both stream anchors use the victim's original ground tile for depth sorting. Lower tiles cover both streams; both can cover objects on upper tiles. City-only garrison impacts retain a single city effect. Active hit smoke suppresses duplicate wreck smoke on the same tile.

The five source images are in `game/assets/smoke-column.webp`; offline row bounds are in `smoke-plume-data.js`. `tools/prepare-smoke-plume.py` pre-renders both sets into `smoke-flow.webp`, a shared 640x1920 atlas of eighty 80x192 frames (4,915,200 decoded RGBA bytes). Offline alpha crop bounds in `smoke-flow-bounds.js` exclude empty pixels while preserving each frame's full-canvas anchor. Runtime loads this atlas and uses one cropped image draw per stream, with no pixel reads, per-unit canvases, flow calculations, image encoding or timers. Existing culling and same-tile merging remain. Up to twelve visible hit/wreck locations paint two streams each; initial bursts are never hidden by this smoke limit. Explosion/blood/spark positions and v70 spark-only mechanical hits are preserved.
