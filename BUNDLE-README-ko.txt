Terha Conquest v1.10.72 — 소스 안내

현재 개발 원본은 GitHub 저장소의 main 브랜치입니다.
전체 소스는 저장소의 Code → Download ZIP으로 내려받을 수 있습니다.
프로젝트 루트에서 python3 build.py로 APK를 만듭니다. Python 3와 Java 17이 필요합니다.
이미지, 음악, WAV 60개, Android 셸, 원래 서명 파일, 빌드 JAR를 포함합니다.
bundle-manifest.json에는 이 버전의 소스 파일 크기와 SHA-256을 기록합니다. 이 안내와 목록 자체는 목록에서 제외합니다.

처음 전달된 v1.10.67의 세 ZIP은 동일한 Terha-Conquest/ 폴더 아래 합치는 방식이었습니다.
후속 수정은 GitHub 저장소의 최신 소스를 기준으로 진행하세요.
