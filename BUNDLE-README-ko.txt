Terha Conquest v1.10.67 — 세 묶음 소스

1. 코드·빌드·서명 ZIP, 지도·유닛 이미지 ZIP, 음악·효과음 ZIP을 모두 내려받습니다.
2. 세 ZIP을 같은 상위 폴더에 풉니다. 모두 Terha-Conquest/라는 동일한 루트 폴더를 사용하므로 내용이 하나로 합쳐집니다. ZIP별로 다른 폴더를 자동 생성하는 옵션은 끄세요.
3. 합쳐진 Terha-Conquest 폴더에서 python3 build.py를 실행합니다. Python 3와 Java 17이 필요합니다.

코드·빌드·서명: 게임 JS/HTML/CSS, 지도 메타데이터, 글꼴, Android 셸, 빌드·서명 도구, 설명서, 검사 코드.
지도·유닛 이미지: 지도, 지형, 유닛·도시·깃발, 시작/로딩 배경, 귀신과 사망 흔적을 포함한 모든 이미지.
음악·효과음: 메뉴 MP3, 게임용 PCM 음원 은행 JS 두 개, 개별 WAV 60개. combat-audio.js 등 재생 로직은 코드 ZIP에 있습니다.

세 ZIP은 기존 v1.10.67 전체 소스와 파일 내용이 동일합니다. 이 설명서와 bundle-manifest.json만 추가했습니다.
향후 처음 작업 공간을 복원할 때는 세 묶음이 모두 필요합니다. 해당 자료가 이미 남아 있으면 바뀐 묶음만 다시 전달하면 됩니다.
이미지가 용량 대부분을 차지하므로 이미지 묶음은 여전히 큽니다.
